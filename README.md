Sorting Algorithms

1.
- Kini nga Java program nag gamit ug three ka sorting algorithms: Bubble Sort, Selection Sort, ug Insertion Sort. 
Ang idea aning sorting is mao ang paghan-ay sa mga numero gikan sa pinakagamay hangtod sa pinakadako. 
Ang kada-algorithm naggamit og lahi nga copy gikan sa original array aron makita ang result sa every sorting method.

How Each Sorting Algorithm Works:

Bubble Sort
- Ang Bubble Sort kay ga compare sa duha ka nagtapad nga numbers.
Kung mas dako ang naa sa wala kaysa sa naa sa tuo, mag-ilis sila og pwesto. 
Balik-balikon ni sya na paagi hangtod mahan-ay ang tanang numero.

Selection Sort
- Ang Selection Sort mangita sa pinakagamay nga number sa array. 
Ibutang dayon dinhi ang maong number sa iyang sakto na pwesto. 
Same gyapon sya balik-balikon hangtod mahuman ang paghan-ay sa tanang numero.

Insertion Sort
- Ang Insertion Sort pud kay magkuha ug isa ka number ug ibutang ni sya sa iyang sakto nga pwesto which is kung aha gyud iyang number belong, 
even nga naay mga numbers nga nauna nang nabutang. Same gyapon magpadayon ni hangtod mahan-ay ang tibuok array iyang output ani naka han-ay 
gikan sa lowest na number hangtod sa pinakadako.

Differences Between the Three Algorithms:

- Ang Bubble Sort naggamit og pagkumpara sa nagtapad nga number ug pag-ilis sa ilang pwesto. 
Ang Selection Sort mangita una sa pinakagamay nga numero sa kada round. 
And lastly Ang Insertion Sort, sa lain nga paagi, from the word nga insert, ani nga way mag insert sya ug number nga naa sa array
ug magbutang sa kada numero sa saktong pwesto ani. Lahi-lahi sila sa proseso pero pareho ang ilang output nga mahan-ay ang mga numero.

Reflection Questions:

1. How does each sorting algorithm arrange numbers? What makes their processes different?
- Ang tulo ka algorithms pareho nga naghan-ay sa mga numero gikan sa gamay hangtod sa dako. 
Ang Bubble Sort nagkumpara sa magtapad nga numero, ang Selection Sort mangita sa pinakagamay nga numero, 
ug ang Insertion Sort magbutang sa numero sa hustong pwesto niini.

2. Among the three sorting algorithms, which one do you think is the easiest to understand and implement? Why?
- Para sa akoa, ang Bubble Sort ang pinakasayon sabton ug buhaton kay easy ra ang proseso niini and mas han-ay siya bisan sa pag process pa lang.
Igo lang magcompare sa duha ka numero ug mag-ilis sa ilang pwesto kung kinahanglan.

3. If the numbers are already sorted, which algorithm do you think would perform better? Explain your answer based on how the algorithms work.
- Para nako, ang Insertion Sort ang mas maayo kung ang mga numero nahapsay na daan. 
Dili na kaayo siya kinahanglan magbalhin-balhin og mga numero kay naa naman sila sa saktong pwesto.

4. What will happen if you add more numbers to your array? How might this affect the performance of each sorting algorithm?
- Kung magdugang og mga numero sa array, mas daghan ang kinahanglan han-ayun sa mismong code or program.
 Mahimong mas dugay ang pagdagan sa tulo ka algorithms tungod kay mas daghan na ang ilang ikumpara ug han-ayun.

5. As a future programmer, why is it important to understand different sorting algorithms instead of using just one?
